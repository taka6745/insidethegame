# Microsoft judging and official requirements

[← Research](README.md) · [Official rules](https://github.com/microsoft/insidethegamehackathon/blob/9c6c99620b06b2b04dcf69a434cdf4d203d19eda/OFFICIAL%20RULES.md)

![Judging weights](judging.svg)

Stage one checks theme/technology fit. Stage two gives each criterion **20%**; ties start with technical implementation. Microsoft selects the panel, with League assistance. [Rules §§2/6](https://github.com/microsoft/insidethegamehackathon/blob/9c6c99620b06b2b04dcf69a434cdf4d203d19eda/OFFICIAL%20RULES.md#6-judges--criteria)

| Criterion | Published emphasis, shortened |
| --- | --- |
| Technical quality | Synthetic-data design, Microsoft technology, maintainable code. |
| Agent design / innovation | Useful AI patterns, orchestration, MCP, collaboration. |
| Real-world impact | Problem significance, production applicability, user/business value. |
| UX / presentation | Intuitive experience, clear video, frontend/backend balance. |
| Category fit | Meets the selected category’s description. |

Categories: overall awards; Foundry; enterprise; multi-agent; Azure cloud-native integration. [Rules §4.2](https://github.com/microsoft/insidethegamehackathon/blob/9c6c99620b06b2b04dcf69a434cdf4d203d19eda/OFFICIAL%20RULES.md#42-hackathon-categories)

| Required | Detail |
| --- | --- |
| Synthetic football events | Ingest → interpret → explain → render → personalise. |
| Original new entry | Created after registration began; rights to third-party material. |
| Public code + working access | Public GitHub URL; accessible demo/test build. |
| Video | **Under two minutes**, real working project, public URL. |
| Language | English material or translations. |

Player identification, pass quality, speed, video event detection and multilingual stories are suggested features. They are not each mandatory. No numeric Microsoft-stack percentage appears in the inspected rules. [Rules §§4.1/4.3–4.9/6.2](https://github.com/microsoft/insidethegamehackathon/blob/9c6c99620b06b2b04dcf69a434cdf4d203d19eda/OFFICIAL%20RULES.md)

## What the brief points toward

![Microsoft challenge pipeline](challenge.svg)

| Specific signal | Meaning for the experience |
| --- | --- |
| Casual fan ≠ analyst | Change explanation depth, not just the colours. |
| Favourite player / club | Make the same match relevant to different interests. |
| Pressure, control, rhythm | Explain changes that a scoreline misses. |
| Timed, machine-readable output | Insight must arrive alongside the relevant moment. |
| Multiple languages | Stories usable across markets. |

[Business cases and evidence](cases.md) connect these signals to fan needs. The [Innovation Studio brief](https://innovationstudio.microsoft.com/hackathons/insidethegamedeveloperhackathon/home) also stresses production controls for enterprise entries and useful handoffs/recovery for multi-agent entries. The [Microsoft workshop](https://developer.microsoft.com/en-us/reactor/series/S-1709/) names play styles, counterattacks and player patterns.
