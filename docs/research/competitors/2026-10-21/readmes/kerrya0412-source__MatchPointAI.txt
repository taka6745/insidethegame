# MatchPoint AI

## Inside the Game Hackathon

MatchPoint AI is an AI-powered football match intelligence platform designed to turn match events into explainable insights for broadcasters, analysts, and viewers.

## Live Application

https://orange-bay-09c579b10.4.azurestaticapps.net

## Features

- Live match simulation and event playback
- Match momentum and pressure analysis
- Tactical intelligence
- AI-generated broadcaster commentary
- Audience-specific match storytelling
- Evidence validation for match insights
- Deterministic commentary fallback

## Technology Stack

### Frontend
- React 19
- Vite 8
- Azure Static Web Apps

### Backend
- Python
- FastAPI
- Azure App Service

### Artificial Intelligence
- Microsoft Foundry
- GPT-5-mini
- Azure Managed Identity

## Explainable AI

MatchPoint AI validates match-event references before presenting intelligence.

AI-generated commentary is checked against verified match facts to reduce unsupported claims.
