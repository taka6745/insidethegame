# Hamzat MatchMind Studio

Explainable match intelligence: live replay, momentum, key moments with evidence,
AI explanations and multilingual recaps (Azure OpenAI).

## Run

```bash
npm install
cp .env.example .env.local   
npm run dev
```

Open http://localhost:3000 and press **Start match**.

Without Azure keys, the AI features run in fallback mode (template text).
