# Master-plan review

**19 October 2026 — target architecture and presentation.** An initial review found flow and clarity errors the earlier record had missed. Fixes then went through 31 single-use fresh reviewers. The loop stopped only when a fresh reviewer found no material issues, and then a separate Fable-model reviewer also found none. Fable rejected the board twice, so the loop restarted twice.

| Area | Corrected |
| --- | --- |
| Flows | Audience choice reaches the backend; presence sets enabled flags; the orchestrator triggers summarise, compress and author; the compressor reads memory; the bucket choice reaches gateway routing; the backlog reaches the gateway; the custom-calculation path returns results; the executor reads through a read-only helper. |
| Ownership | Zone-coloured node titles; Event Hubs drawn as a shared stream; narrative "Enabled targets" read the backend catalogue; GRF has its own colour. |
| Legend | Arrows show data direction; two heads mean two-way exchange; dashes mean Event Hubs or Service Bus messages; colour is the sending service (swatches included); dots mark branches; gaps mark crossings. |
| Presentation | Labels sit on their lines; text is centred and wrapped to real font metrics; titles are one size; icons are tinted by service; frontend panels are evenly spaced; the video panel shows a broadcast view; Service Bus carries its product icon. |

The board is generated by `.github/scripts/render_master_plan.py`, which places crossing gaps and branch dots automatically. It is exported through the Excalidraw canvas (padding 40). It has **512 elements and 11 embedded assets**. Application code was unchanged.
