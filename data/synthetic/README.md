# Collected synthetic data

[← Data](../README.md) · [Browse files by competitor](../../competitors/README.md#their-data) · [Sources, licences and checksums](../../competitors/data/datasets.json)

**40 files from 10 public competitor repositories.** Fictional matches, generated events and demo fixtures; no verified real match dataset in this collection.

Files are grouped by `owner__repository`. The inventory records each source commit, URL, SHA-256 and repository licence. Original bytes are preserved except the explicitly labelled VYBE fixture extracted from TypeScript. ZIP samples are labelled too. A public repository does not itself grant a data reuse licence; missing licences remain unknown.

The daily competitor refresh writes samples here without executing competitor code. These are reference samples, separate from our [GRF-generated matches](../GoogleResearchFootball/README.md).
